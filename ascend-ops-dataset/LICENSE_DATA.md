# Dataset license and provenance

This directory is a compilation of task metadata, prompts, references, and selected upstream operator materials. The compilation structure and dataset-building scripts are provided for research and reproducibility. Embedded upstream code and documentation retain their original copyright and license terms.

The root MIT License does **not** grant additional rights to Huawei CANN source code, CANN documentation, GNU build utilities, or any other third-party material. Source URLs and provenance fields should be retained when creating derived datasets.

The public repository distinguishes:

- 682 task-language records suitable for corpus-level analysis.
- 5 representative tasks with local test-generation and verification scripts.

Presence in the corpus does not mean the operator was compiled or validated on hardware.
